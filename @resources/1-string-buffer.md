# Dart ও Flutter-এ Normal String Concatenation এবং StringBuffer-এর পার্থক্য

Dart এবং Flutter-এ **Normal String Concatenation (`+`)** এবং **`StringBuffer`**-এর মূল পার্থক্য হলো **মেমরি ব্যবহার (Memory Usage)** এবং **পারফরম্যান্স (Performance)**।

সহজ বাংলায় বিষয়টি নিচে ব্যাখ্যা করা হলো:

## ১. Normal String Concatenation (`+` বা `+=` ব্যবহার করে)

Dart-এ সাধারণ `String` হলো **Immutable** (অপরিবর্তনশীল)। অর্থাৎ, একবার কোনো স্ট্রিং তৈরি হলে সেটিকে আর পরিবর্তন করা যায় না।

- **কীভাবে কাজ করে:** আপনি যখন `+` দিয়ে দুটি স্ট্রিং জোড়া লাগান, তখন আগের স্ট্রিংটি পরিবর্তন হয় না। বরং মেমরিতে একদম **নতুন একটি স্ট্রিং অবজেক্ট** তৈরি হয়।
- **সমস্যা কোথায়:** আপনি যদি কোনো `for` লুপের ভেতর ১০০০ বার স্ট্রিং জোড়া লাগান, তবে মেমরিতে ১০০০টি আলাদা অবজেক্ট তৈরি হবে। এতে অ্যাপের মেমরি নষ্ট হয় এবং অ্যাপ স্লো হয়ে যেতে পারে।

## ২. StringBuffer ব্যবহার করে

`StringBuffer` হলো **Mutable** (পরিবর্তনশীল)। এটি একটি খালি বক্স বা ঝুড়ির মতো কাজ করে।

- **কীভাবে কাজ করে:** আপনি যতবার `.write()` দিয়ে নতুন লেখা যোগ করবেন, সব ওই একই বক্সের ভেতর জমা হতে থাকবে। মাঝপথে মেমরিতে নতুন কোনো স্ট্রিং তৈরি হবে না।
- **সুবিধা কোথায়:** সব লেখা জমা হওয়ার পর যখন একদম শেষে `.toString()` কল করবেন, তখন **শুধুমাত্র একবার** মেমরিতে ফাইনাল স্ট্রিংটি তৈরি হবে। ফলে মেমরি বাঁচে এবং অ্যাপ অনেক ফাস্ট কাজ করে।

## সংক্ষেপে মূল পার্থক্য

| বৈশিষ্ট্য             | Normal Concatenation (`+`)                 | StringBuffer                                      |
| :-------------------- | :----------------------------------------- | :------------------------------------------------ |
| **ধরন**               | Immutable (পরিবর্তন করা যায় না)।           | Mutable (পরিবর্তন করা যায়)।                       |
| **মেমরি খরচ**         | প্রতিবার জোড়া লাগানোর সময় নতুন মেমরি নেয়।  | সব লেখা এক জায়গায় জমা রাখে, শেষে একবার মেমরি নেয়। |
| **গতি (Speed)**       | লুপের ভেতর ব্যবহার করলে অনেক স্লো হয়ে যায়। | লুপের ভেতর ব্যবহার করলে অনেক ফাস্ট কাজ করে।       |
| **কখন ব্যবহার করবেন** | ২-৩টি ছোট লেখা বা ভেরিয়েবল জোড়া লাগাতে।    | লুপের ভেতর বা অনেক বড় টেক্সট তৈরি করতে।           |

## কোড উদাহরণ

### সাধারণ পদ্ধতি (লুপের জন্য খারাপ)

```dart
String text = '';
for (int i = 0; i < 1000; i++) {
  text = text + '$i '; // প্রতিবার মেমরিতে নতুন String তৈরি হচ্ছে
}
```

### StringBuffer পদ্ধতি (লুপের জন্য সেরা)

```dart
final buffer = StringBuffer();
for (int i = 0; i < 1000; i++) {
  buffer.write('$i '); // শুধু বাফারে জমা হচ্ছে, নতুন String তৈরি হচ্ছে না
}
String text = buffer.toString(); // একদম শেষে একবার String তৈরি হলো
```
