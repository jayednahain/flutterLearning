# Dart Initializer List (`:`)

Dart-এ কনস্ট্রাক্টর সিগনেচারের ঠিক পরে যে কোলন (`:`) ব্যবহার করা হয়, তাকে অফিসিয়ালি **Initializer List** বলে। 

এটি কনস্ট্রাক্টরের মূল বডি `{ ... }` চালু হওয়ার **আগেই** রান হয়। এর মূল কাজ হলো অবজেক্ট পুরোপুরি তৈরি হওয়ার আগেই ক্লাসের ভেরিয়েবলগুলোতে (বিশেষ করে `final` ভেরিয়েবলে) মান (value) সেট করে দেওয়া।

---

### কনস্ট্রাক্টরের কাজের ক্রম (Execution Order)

```dart
class Client {
  // ১. কনস্ট্রাক্টর ডেফিনিশন (প্যারামিটার রিসিভ করে)
  Client({required String baseUrl})
      // ২. ইনিশিয়ালাইজার লিস্ট (বডি চালু হওয়ার আগেই final ভেরিয়েবলে মান সেট করে)
      : _baseUrl = baseUrl.endsWith('/') ? baseUrl : '$baseUrl/' 
      // ৩. কনস্ট্রাক্টর বডি (ভেরিয়েবল রেডি হওয়ার পর মূল কোড রান হয়)
      {
        print('Client ready for $_baseUrl');
      }

  final String _baseUrl;
}
```

---

### কখন `:` ব্যবহার করবেন এবং কখন করবেন না?

| পরিস্থিতি (Scenario) | `:` ব্যবহার করবেন? | কারণ |
| :--- | :--- | :--- |
| **`final` ভেরিয়েবলে লজিক বা হিসাব করে মান বসাতে হলে** (যেমন: `area = width * height`) | **হ্যাঁ** | Dart-এর নিয়ম অনুযায়ী কনস্ট্রাক্টর বডি `{ ... }`-এর ভেতরে `final` ভেরিয়েবলে মান বসানো যায় না। |
| **সরাসরি মান বসালে** (`this.name`) | **না** | কোনো আলাদা হিসাব-নিকাশ না থাকায় Dart সরাসরি প্যারামিটার থেকে ভেরিয়েবলে মান বসিয়ে দেয়। |
| **ভেরিয়েবল `final` না হলে** (`late` বা সাধারণ ভেরিয়েবল) | **না** | `final` না হলে কনস্ট্রাক্টর বডি `{ ... }`-এর ভেতরেই নিরাপদে মান বসানো যায়। |

### উদাহরণসমূহ

**১. কোলন (`:`) ব্যবহার করে (বডি রান হওয়ার আগেই হিসাব করে `final` ভেরিয়েবলে মান বসানো):**
```dart
class Rectangle {
  final double width;
  final double height;
  final double area;

  Rectangle({required this.width, required this.height})
      : area = width * height {
    print('Area is $area');
  }
}
```

**২. কোলন (`:`) ছাড়া (সরাসরি `final` ভেরিয়েবলে মান বসানো):**
```dart
class User {
  final String name;
  final int age;

  User({required this.name, required this.age}) {
    print('User $name created');
  }
}
```

### এক নজরে মূল বিষয়গুলো
* **অফিসিয়াল নাম:** Initializer List (`:`)।
* **কখন চলে:** যখনই ক্লাসটি থেকে নতুন অবজেক্ট তৈরি করা হয় (`Client(...)`), ঠিক তখনই `{ ... }` বডি চালু হওয়ার **আগে** এটি রান হয়।
* **মূল উদ্দেশ্য:** কোনো শর্ত বা হিসাবের মাধ্যমে `final` ভেরিয়েবল ইনিশিয়ালাইজ করা অথবা ইনহেরিটেন্সের ক্ষেত্রে `super(...)` কল করা।
